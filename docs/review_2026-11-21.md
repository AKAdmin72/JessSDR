## Как продолжить

1. Подключить обе платы.
2. Прошить:
   - `cd esp32 && ./flash.sh`
   - `cd sdr_esp && ./flash sram` (сначала в SRAM: после выключения питания
     вернётся старая прошивка из flash)
3. Пройти чек-лист ниже.
4. Если всё хорошо:
   - `cd sdr_esp && ./flash flash`
   - коммит, затем по желанию релиз в `releases/` с тегом `working-2026-11-2x`.

## Где был спор

- **Окно по умолчанию оставлено OFF.** Это выбор пользователя: широкие пятна
  станций. Минус OFF: «юбки» вокруг сильных станций. BH есть в меню, сравнить на
  вещалках выше 7.2 МГц.
- **`EQ_SLOPE` без пункта меню:** это одна константа. Если «юбки» станут хуже,
  её можно вернуть ближе к 1.94.

## Чек-лист на железе

- [ ] Перестройка в режиме SCROLL: бугров по краям нет, чёрных квадратов нет.
- [ ] Режим STATIC работает как раньше.
- [ ] Края спектра (±35 кГц): нет ложных станций-алиасов.

      На SSB может показывать на несколько dB меньше прежнего, потому что берёт
      среднюю мощность за блок 10 мс.

      поправить `FPGA_DBM_1LSB` в `fpga.h`.

      расчётное усиление up4 ~0 dB.
- [ ] Шумодав срабатывает при открытом меню.
- [ ] Window: BH против OFF.
- [ ] Самотест ESP при загрузке PASS, VERSION 7 читается.
